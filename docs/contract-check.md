# Проверка контракта колодой К1–К10

Дата: 15.11.2026.

Job — задание на асинхронное выполнение операции. Жизненный цикл включает состояния `created`, `running`, `finished`, `failed` и `cancelled`. Проверка основана на API-контракте, документе [job-lifecycle.md](job-lifecycle.md) и принятых ADR-0001–0003.

| **Карта**                          | **Ответ контракта**                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ---------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **К1 Двойной клик**                | Два запроса с одинаковым `Idempotency-Key` от одного пользователя создают одну Job. Первый запрос возвращает `201`, повторный — `200` с существующей Job, прежним `id` и актуальным статусом. Даже если параметры отличаются, новая Job не создаётся. Источники: [OpenAPI](api/openapi.yaml), `POST /api/tasks`; [ADR-0001](adr/0001-idempotency.md).                                                                                                          |
| **К2 Ответ потерялся**             | Если Job создана, но ответ потерялся, клиент повторяет запрос с тем же `Idempotency-Key`. Сервис возвращает существующую Job с `200`, прежним `id` и актуальным статусом. Если PostgreSQL или Redis недоступны при создании, возвращается `503`, Job не сохраняется. Источники: [OpenAPI](api/openapi.yaml), `POST /api/tasks`; [ADR-0001](adr/0001-idempotency.md), [ADR-0002](adr/0002-background-worker.md).                                                |
| **К3 Неизвестная операция**        | Неизвестный тип операции отклоняется с `422` в формате `Error`, код ошибки — `validation_error`. Job не создаётся. Источник: [OpenAPI](api/openapi.yaml), `TaskType`, `TaskCreate`, `ValidationError`.                                                                                                                                                                                                                                                         |
| **К4 Кривые параметры**            | Отсутствующее обязательное поле, неверный тип или недопустимое значение отклоняются с `422` в формате `Error`. В `details.fields` указывается ошибочное поле и причина ошибки. Job не создаётся. Источник: [OpenAPI](api/openapi.yaml), `TaskCreate`, схемы параметров, `ValidationError`.                                                                                                                                                                     |
| **К5 Воскрешение**                 | Ручной `retry` разрешён только для Job со статусом `failed`: возвращает `200`, переводит её в `running`, очищает прежнюю ошибку и сохраняет прежний `id`. Для остальных статусов возвращается `409 invalid_transition`. Автоматические повторы ARQ происходят отдельно внутри `running`. Источники: [OpenAPI](api/openapi.yaml), `POST /api/tasks/{task_id}/retry`; [job-lifecycle.md](job-lifecycle.md); [ADR-0002](adr/0002-background-worker.md).           |
| **К6 Отмена**                      | Отмена поддерживается через `POST /api/tasks/{task_id}/cancel`. Из `created` задание не запускается, из `running` статус становится `cancelled`, Tool прерывается, а уже полученный результат отбрасывается. Успешный ответ — `200`. Отмена терминальной Job возвращает `409 invalid_transition`. Источники: [OpenAPI](api/openapi.yaml), `POST /api/tasks/{task_id}/cancel`; [job-lifecycle.md](job-lifecycle.md); [ADR-0002](adr/0002-background-worker.md). |
| **К7 Огромный вход**               | Для параметров заданий действуют ограничения схем OpenAPI. Например, `name` — до 200 символов, `fetch` — до 20 URL, `file_checksum.max_bytes` — до 100 МБ. Превышение ограничений параметров приводит к `422`, превышение допустимого размера скачиваемого файла — к ошибке Tool `too_large`. Источник: [OpenAPI](api/openapi.yaml), схемы параметров и `ValidationError`.                                                                                     |
| **К8 Чужой или несуществующий ID** | Чужое, удалённое и несуществующее задание неразличимы для API: возвращается одинаковый `404` в формате `Error`, без раскрытия данных чужого задания. Некорректный UUID отклоняется с `422`. Источники: [OpenAPI](api/openapi.yaml), `GET /api/tasks/{task_id}`; [ADR-0003](adr/0003-job-deletion.md).                                                                                                                                                          |
| **К9 Перезапуск сервера**          | При аварийном завершении воркера ARQ повторяет выполнение в пределах настроенного числа попыток. После исчерпания попыток Job переходит в `failed`. Восстановление Job, оставшейся в `created` из-за сбоя между сохранением в PostgreSQL и постановкой в Redis, сознательно не закрывается в текущем решении. Источник: [ADR-0002](adr/0002-background-worker.md), раздел «Цена решения».                                                                      |
| **К10 Внешний сервис**             | В `fetch` недоступность отдельного URL не приводит к сбою всей Job: для такого URL возвращается элемент результата с `ok: false` и кодом ошибки. Успешные ответы обрабатываются отдельно, JSON разбирается, текст ограничивается установленным размером. Ошибки отдельных URL являются частью результата, а Job может завершиться со статусом `finished`. Источник: [OpenAPI](api/openapi.yaml), `FetchResult`, `FetchItem`.                                   |
